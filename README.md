## Data Detectives Project

**Project Overview**

Data Detectives is an interactive data analysis tool designed to upload, inspect, clean, analyze, and visualize CSV datasets.

**Project Features**
- Upload and preview CSV datasets.
- Identify missing values, duplicates, and data inconsistencies.
- Search, sort, and filter records.
- Edit data manually and apply automatic cleaning rules.
- Calculate descriptive statistics.
- Visualize distributions and detect outliers.
- Export cleaned datasets and change logs.
